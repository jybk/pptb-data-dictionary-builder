Data Dictionary Builder

Paste the address of an open record or view from a model-driven app, or of a form in the make.powerapps.com designer. A table name such as account works too.

Options
Columns
Export

What you get

  • Every field on the form or view, in the order it appears on screen: header, then each tab and section, then footer.
  • Data dictionary columns for each field: label, logical name, data type, format, length or range, required level, allowed values, lookup targets and description.
  • Export to Excel, CSV, Markdown or JSON, or copy the table straight into a document.

The tool only reads form, view and column definitions. It does not read or change any records.
